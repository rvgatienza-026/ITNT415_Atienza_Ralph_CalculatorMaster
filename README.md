## Project Description

Calculator Master is a simple menu-driven Python calculator developed using Git and GitHub. The project demonstrates Python programming, Git branching, source code management, Pull Requests, and merge operations.

## Branch Structure

- main
- addition_Atienza
- subtraction_Atienza
- multiplication_Atienza
- division_Atienza

## Program Features

- Addition
- Subtraction
- Multiplication
- Division
- Menu-driven interface
- Continuous execution
- User input validation
- Invalid input handling
- Division-by-zero handling
- Exit option

## Git and GitHub Workflow

Each calculator operation was developed using a separate feature branch. Each feature branch contains at least two meaningful commits before being submitted through a Pull Request and merged into the main branch.
